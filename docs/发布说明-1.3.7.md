# 云盘工作台 1.3.7

修复便携版点击“重启更新”时错误提示 `ENOENT, not found in ...resources/app.asar` 的问题。

- 更新器使用 Electron 原始文件系统检查实际 ASAR 文件，避免将归档文件误当作虚拟目录。
- 增加真实打包程序中的安装 IPC 回归，覆盖 Windows 和两种 macOS 架构；测试会完成安装辅助脚本准备，但不会替换用户程序或访问真实账号。
- 资源确实缺失或 ASAR 路径实际为文件夹时，显示明确的中文提示。
- 保留 1.3.6 的 Ed25519 更新签名、大小/SHA256 校验及全部安全加固。

**1.3.5 / 1.3.6 用户首次需手动下载并完整解压 1.3.7，运行新版程序。** 旧版在替换程序之前就会被错误检查阻止，无法靠发布服务器绕过。账号与授权仍位于独立用户数据目录，正常运行新版会继续使用它们；不要清空本地数据。

测试时出现的 `ERR_FAILED (-2) loading ...index.html` 是隔离复现脚本在页面加载完成前关闭窗口造成的加载中断；该测试已改为等待应用页面就绪后退出。未修改用户下载的旧程序或其真实账号数据。

Windows 下载 Windows-x64；Apple Silicon Mac 下载 macOS-arm64；Intel Mac 下载 macOS-x64。Mac 仍采用 ad-hoc 系统签名，未做 Apple Developer ID 签名及公证。
