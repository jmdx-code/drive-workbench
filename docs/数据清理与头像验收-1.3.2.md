# 1.3.2 数据与记录清理、账号头像

日期：2026-10-22。

## 本地清理

任务记录支持单条删除和批量清理已完成、部分完成任务。删除头记录、状态记录与明细表采用一个 SQLite 事务，明细中的调用统计与日志一起删除。整批先核验，任何执行中任务或无效 ID 都不会造成前半批先被删除。暂停记录允许明确确认后删除，但在途操作尚未结束时拒绝删除，避免迟到的写入重建任务。

表格上方“清空扫描”清理当前账号的扫描结果；“设置 → 数据与记录管理”可以清空全部账号的扫描结果。清理本地目录不请求 Google，也不改变网盘文件。

“设置 → 数据与记录管理”以及“账号与授权 → 管理账号与数据”可移除本地账号，连同其授权连接、头像和扫描结果，保留任务历史。该操作不撤销 Google 端应用授权。暂停任务保留在历史中，重新连接账号后可手动继续或对账。

重置需要在独立确认弹窗输入“清空本地数据”，后端同样校验确认文字。清空 SQLite 中账号、加密连接、任务及明细、设置，清理运行时计划、扫描和列宽偏好，并重新初始化授权服务和 Drive 适配器。网络操作、扫描或授权尚未结束，或任务仍有在途请求时拒绝重置。导出的 CSV、HTML 等独立文件保留。

所有清理均只针对本软件的本地数据，不删除 Drive 文件，不撤销已完成的分享、转让等操作。删除暂停任务后无法继续或对账，界面确认文字对此有明确说明。

## 真实头像

账号身份响应增加 `photoLink` 字段，新授权沿用原身份请求，无需增加 OAuth 权限。旧账号首次读取资料补齐；若补取资料时触发令牌刷新，复用刷新过程中已经取得的身份响应，不重复查询 `about`。

图片在主进程下载，只接受 HTTPS Google 图片域名，每次重定向重新校验，图片请求不携带 OAuth 令牌。限制下载时长、大小与格式；通过 Electron 解码后转换为 96px PNG，以 data URL 存入账号记录。渲染进程仅显示本地图片，不扩大内容安全策略。

缓存一天，过期在下次正常启动时重新查询头像地址并下载；账号授权或导入后也会补齐头像。手动刷新可立即重查。同账号并发读取合并为一次。没有照片时显示首字母；网络失败保留已有缓存，解码或显示失败回退首字母。授权失效沿用现有重新授权引导。
