# 1.3.5 便携发布验收

2026-10-22，源码及发布文件公开于 jmdx-code/drive-workbench。

- 正式发布：https://github.com/jmdx-code/drive-workbench/releases/tag/v1.3.5
- 三平台构建与发布记录：https://github.com/jmdx-code/drive-workbench/actions/runs/39781228906
- 产物：Windows x64、macOS arm64、macOS Intel x64 三个免安装 ZIP，以及统一 SHA256SUMS.txt。
- 三个平台均在各自原生 runner 上完成依赖安装、128 项核心测试、构建、打包、实际启动和系统凭据加密往返校验。
- Windows 正式包通过文件管理、所有权转让、目录结构、跳过规则、数据清理、头像、API/并发及更新确认界面回归；打包内容、版本及图标校验通过。
- Windows 更新辅助进程在隔离目录实际执行：等待旧进程退出、解压真实便携 ZIP、替换程序、启动新版、保留用户目录及原程序备份。本地和云端均通过。
- 使用软件更新器从公开 GitHub 最新稳定版接口，匿名下载正式发布的 Windows ZIP，SHA256 验证成功，状态进入 ready；模拟旧版本为 1.3.4，检测到最新 1.3.5。未更新用户正在使用的程序或账号数据库。
- 修复了原锁文件中不可下载的间接依赖；重新生成锁文件后核验 179 个公开 tarball 均可下载。Windows 打包会在缺少运行时时显式安装 Electron，干净机器可以重现。
- 发布构建任务只读，汇总发布任务才有写权限。发布标签与 package.json 版本严格匹配，全部通过后才上传三种平台包和校验文件。

Mac 包采用 ad-hoc 签名并通过 codesign 深度检查，没有 Apple Developer ID 签名及公证。runner 启动及凭据校验已通过；真实用户的 Gatekeeper、钥匙串提示和跨版本钥匙串授权仍需在用户 Mac 上确认。

后续：更新版本号并提交源码，在 GitHub 发布对应版本的 Release 即触发自动构建。客户端自动检查和下载，用户确认重启后更新，不强制中断任务。软件在有写入权限的目录使用；用户数据独立于程序目录，旧程序保留作回滚。

本次整理没有永久删除旧工程资料（自动审批拒绝该操作），详见“本地目录整理.md”。正式版、源码和参考资料现已分开，测试产物、个人配置和数据库均不上传仓库。
