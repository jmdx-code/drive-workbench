# 1.2.1 验收记录

日期：2026-10-21。

新增默认关闭的“跳过不可转让的子项，继续移动父文件夹”，仅在递归转让且移动到目标账号根目录时可用。明确不可转让的子项标记为 skipped，单独展示和导出原因，不计入已验证数量，不删除其直接访问权限。只移动已验证转让的所选顶层项目，保留内部层级。父文件夹不可跳过；未解决的失败或未知状态仍阻止移动。原严格模式保持默认。
