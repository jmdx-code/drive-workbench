# 云盘工作台 1.3.5

多账号 Google Drive 文件与权限管理工具。双击“云盘工作台.exe”启动，保留整个程序目录。升级前先关闭旧窗口；升级不会清空已保存的账号授权、设置和任务。

## 便携版与更新

1.3.5 / 1.3.6 存在安装前 ASAR 检查误报问题；若点击“重启更新”出现 `ENOENT ...resources/app.asar`，请手动下载并完整解压 1.3.7 或更新版本后启动。账号与授权保存在独立用户目录，无需清空本地数据。新版后续更新已修复这项检查。

Windows 下载 Windows-x64 ZIP，完整解压运行 exe。Mac 下载 macOS-arm64（Apple Silicon）或 macOS-x64（Intel）ZIP，解压运行 app，可把 app 放到自己的应用程序目录；目前只有 ad-hoc 签名，没有 Apple 开发者签名及公证，首次打开可能需要在系统“隐私与安全性”中允许。

正式便携版启动后自动检查并下载更新；本次安全修订先验证 Ed25519 更新清单签名，再核对包大小和 SHA256，准备完成后提示“重启更新”。签名缺失或错误时保留当前程序，不安装更新。也可在设置中检查更新。由用户确认重启，任务执行中须先暂停并等待请求结束；不强制打断任务。更新保留本地账号、授权、设置和任务，旧程序作为同级 backup 目录保留，目录替换失败会尝试恢复旧版。请把程序放在自己有写入权限的目录。更新异常可查看用户数据目录中的 `updates/update.log`。此前只验证 SHA256 的旧客户端首次升级仍依赖原有发布渠道信任；新客户端后续更新必须通过签名验证。

## 本地数据与记录清理

- 任务记录中，每条已停止执行的记录可单独删除，也可批量“清理已结束任务”（已完成、部分完成）。删除同时清理本机明细、日志和调用统计。执行中或暂停后请求尚未结束的任务不能删除。暂停记录删除后无法继续或对账，请先核实结果未知的操作；需要留档请先导出 CSV。
- 文件表格上方“清空扫描”只清理当前账号的本次目录；“设置 → 数据与记录管理”可清空全部账号扫描结果。之后查看最新目录需重新扫描。
- 设置或账号授权窗口可进入“数据与记录管理”，移除本地账号及其全部授权、头像与扫描结果，历史任务保留。再次使用需要重新导入配置并授权；这不会撤销 Google 端已授予的应用访问权限。
- “重置本地数据”需要输入“清空本地数据”确认，清空本机账号、授权、头像、任务及日志、扫描结果和应用设置。扫描、授权等操作进行中，或任务请求仍在途时禁止重置。应用之外已导出的文件保留。

上述清理均不删除 Google Drive 文件，也不会撤销已经完成的分享、转让、重命名等操作。

## 账号头像

连接账号后优先显示 Google 提供的真实头像；没有照片或加载失败时显示首字母。头像存储为本地 96px PNG，缓存一天，过期后下次启动更新。可在“数据与记录管理”手动刷新。首次补取旧账号资料每账号增加一次身份查询；后续缓存有效期内不重复读取。新授权复用现有身份响应，不增加身份请求，也不需要额外授权范围。头像图片下载为单独网络请求，不携带 OAuth 令牌。

## 首次连接

1. 点击“账号与授权”，导入 Google Cloud 中 Desktop app 类型的 OAuth 配置文件。Google Cloud 项目需要启用 Google Drive API；测试中的 OAuth 项目需将使用的 Gmail 加入测试用户。
2. 点击“浏览器授权”，在系统浏览器选择正确的 Google 账号并同意访问。已有 authorized_user 类型 token.json 也可导入。
3. 每个 Google 账号独立列在左侧，可重复添加账号或授权连接。

软件不内置第三方 OAuth 配置。授权令牌通过 Windows 系统加密保存在本机。正式界面不显示演示账号和演示模式入口。

## 浏览与文件操作

选择账号、扫描范围和可选目录后点击“扫描”。最大扫描层级默认不限制；勾选后只读取指定深度。扫描后的搜索、筛选、排序与目录展开在本地完成，不重复读取网盘。顶部统计随搜索、所有者、文件类型和当前目录变化；折叠目录不改变统计。

复选框选择文件，Ctrl 多选、Shift 连选或拖动框选；点击文件夹展开，右键可进入目录。表头列分隔线可拖动，双击恢复默认宽度。窄窗口可在表格内横向滚动。未知大小与权限不会当作零或私密。

右侧提供权限管理、链接复制、重命名、移动、文件副本、回收与恢复等操作；“更多文件操作”包含新建文件夹、导入链接和导出本次目录。按钮不可用时可悬停查看原因，必要时刷新操作权限。

## 权限与所有权

权限修改先配置、生成变更预览，再确认执行。默认保持未配置的设置，不擅自修改父目录共享。协作者、群组、域和公开链接分别控制；高级组合功能在独立入口中保留。

转让所有权需要连接源与目标账号。可包含文件夹后代，逐项转让并核验；默认保留原账号编辑权限。另有“移除原账号访问权”和“转让后移到目标账号根目录”两个独立选项，均默认关闭。移动选项保留所选文件夹内部层级；直接授权需另行清理。可能产生 Google 系统通知邮件。

原账号通过父目录继承的访问不能直接在子文件上删除；任务会明确提示。不要把部分步骤失败理解为前面的操作全部没有执行，以任务明细和复核结果为准。

## 任务与恢复

任务记录支持暂停、继续/对账、执行明细和 CSV 导出。关闭程序后任务不在后台运行，重启后中断任务暂停并等待对账；结果未知的写入不会盲目重复创建文件。

## 使用边界

- 目录是本次扫描快照；外部变动需要重新扫描，不是实时同步。
- 不提供上传下载、永久删除、表格内容编辑、挂载、双向同步和全部账号聚合。
- 不支持文件夹递归复制；共享云端硬盘和快捷方式不支持个人所有权转让。
- 实际操作受 Google 账号权限、组织策略、配额和网络状态影响。

程序及第三方组件许可随目录提供。请保留 LICENSE、LICENSES.chromium.html、第三方许可.md 和 licenses 文件夹。

## 混合所有者文件夹的转让

递归转让文件夹统一采用“尽量完成”：自动跳过明确不可转让的子项，继续处理可转让项目。预览会提示文件夹中非本人所有的项目数量，并列出处理、跳过或被阻止的项目以及原因；确认执行前不会修改网盘。所有者检查覆盖本次完整扫描的后代，即使当前所有者筛选排除了这些项目，仍会提示。

如需完整搬移层级，请勾选“包含文件夹内后代”和“转让后移到目标账号根目录”。父文件夹必须成功转让，只有全部可处理项目已验证或明确跳过后才移动顶层目录。未勾选移动选项时，仍按尽量完成转让，但保持文件原位置。

跳过项保留原所有者，不清理其直接访问权限；移动目录可能改变继承访问，目标账号不一定能访问跳过的文件。授权异常、限流、超时或结果未知不会自动当作跳过，仍需处理或对账。报告单独记录已跳过数量和原因。新规则只应用于新建预览，历史任务保留原先冻结的执行策略。

## 并发、限流与请求统计

全局不设业务并发上限，每账号最高 18、每授权连接最高 6；单个连接最多 6，三个可用连接才能达到账号 18。默认开始即按可用上限执行，不做起始爬升。旧设置中的全局字段不再使用，超出新上限的旧值自动限制到 18/6，较低设置保留。

账号级限流统一作用于该邮箱全部连接，项目级限流统一作用于同项目连接，不通过换连接立即重试。同轮在途请求报错只减半一次，最低为 1；同时遵守 Google 指示的等待时间。冷却结束后无新限流持续 60 秒，逐级恢复到设置上限。设置页显示实际在途请求、当前有效上限、近一分钟请求量及限流原因。普通网络错误、权限不足及授权失效分别处理，不当作并发限流。共享或每日配额限制不进行短时间反复写入，保留明确失败原因并进入较长冷却。

新导入 OAuth 配置时会保留其中的项目标识。历史连接如无项目标识，项目级限流时按保守共用组退避；重新导入对应 Desktop OAuth 配置并授权可补齐项目归属。并发和冷却运行状态只属于当前软件进程；重启后的中断任务仍需手动继续/对账。

转让状态短暂未同步时，按 1、2、4、8 秒间隔复查；持续无法确认才暂停。邀请或接收回包丢失时，先读取远端状态对账，不盲目重复发送邀请。自动等待期间仍可暂停任务。

任务卡片显示执行阶段 API 读取、写入、重试/复查及限流响应次数；CSV 同样包含统计和历史。读取与写入按实际发出的 Drive HTTP 请求计算，写入计数也包含被服务器拒绝的请求；请求次数不等于 Google 配额单位。扫描与预览不计入任务执行统计，OAuth 令牌请求也不计入。历史任务没有记录过的调用量不作补估。
