# 云盘工作台 1.3.6

本版为安全修订，保留现有账号、授权、任务与网盘操作流程。

- 修复 OAuth 本地回调异常处理、发布版开发模式入口及 CSV 公式注入防护缺口。
- 收紧主窗口 IPC、CSP 和浏览器权限，保留沙箱与上下文隔离。
- Electron 更新至 44.9.3；Windows 图标/版本资源编辑由停止维护的 rcedit 迁移至 resedit。
- 新增 Ed25519 更新清单验证，绑定版本、平台、架构、包大小和 SHA256；缺失或错误签名不会安装。
- GitHub Actions 自动构建、测试、签名并上传三个平台包，日常无需手工下载或签名。

Windows 请下载 Windows-x64；Apple Silicon Mac 请下载 macOS-arm64；Intel Mac 请下载 macOS-x64。完整解压后运行，保留整个程序目录。

从旧版首次升级仍依赖原发布渠道的可信性；1.3.6 及后续客户端只接受签名更新。保留 SHA256SUMS.txt 兼容旧客户端。Mac 仍使用 ad-hoc 系统签名，尚未取得 Apple Developer ID 签名与公证。

本地验证已通过 147 项单元测试、生产构建、Windows 打包/完整业务回归、签名篡改拒绝检查及实际更新安装；三平台发布包由本次 GitHub Actions 再次构建和验证。依赖审计及剩余边界见同目录安全审核报告。
