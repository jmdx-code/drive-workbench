# 本地目录整理

2026-10-22 整理：

- `core/`、`desktop/`、`src/`：业务与界面源码。
- `scripts/`、`tests/`：必要的构建、发布和自动化回归，不与便携版分发。
- `.github/workflows/`：main/PR 测试与发布后自动构建。
- `assets/branding/`、`public/`：图标源文件及各平台图标。
- `docs/`：使用说明、设计与验收记录；历史 API 对比保存在 `benchmarks/`。
- `release/`：当前便携包及最近两个可用回滚版本，本地构建会更新“当前版本.json”。
- `node_modules/`、`dist/`、`dist-desktop/`、`本地测试/`：本地开发所需或可重建目录，均不上传 GitHub。
- 四份原参考项目及原需求记录集中到 `参考资料/`，保留原文件内容，不上传。

旧归档、历史源码备份、旧测试截图、1.2.2/1.3.0 重复构建及早期 ZIP 共约 3.90 GB 已移出项目，位于相邻目录 `网盘管理工具-旧构建与测试资料-20261022/`。永久删除被自动审批拦截，返回 `blocked by policy`，未提供更具体原因；未尝试绕过。移动只整理工作目录，没有释放这部分磁盘空间，后续可由用户自行确认删除。

1.3.4 开发验证包也已移入上述目录；release 中保留当前 1.3.5 和此前可用的 1.3.1、1.3.2 版本。后续运行测试产生的新报告仍写入被 Git 忽略的 test-results。

真实账号数据库、OAuth 配置及用户任务数据不在工程中，未清理、未上传。提交前已检查常见 Google/GitHub 密钥及数据库文件；仓库忽略授权 JSON、token、数据库、证书、环境文件、参考项目和构建产物。代码中的授权字段与短占位字符串用于回归测试。
