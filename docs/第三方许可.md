# 第三方组件与许可

新实现没有直接复制四款参考工具的业务源代码。原参考资料集中保存在本地“参考资料”目录，不上传仓库或纳入发行包。

- Electron：MIT；运行时附带 LICENSE 和 LICENSES.chromium.html，需与应用一起分发。
- React 和 React DOM：MIT。
- Lucide React：ISC。
- TanStack Virtual：MIT，用于大目录列表虚拟渲染。
- TypeScript：Apache 2.0，构建使用。
- Vite、Vitest、Playwright Core、Electron ASAR：各自源码包附带许可证，均为构建或测试依赖。
- Electron Packager、Sharp、rcedit：构建工具，用于平台打包与图标生成，不作为运行依赖放入便携包。

发行脚本保留 Electron 自带许可，并将直接运行时依赖的 LICENSE 文本复制到 licenses 目录。依赖的确切版本及完整性摘要保存在 package-lock.json，使用 npm ci 恢复。发布时应保留所有实际打包组件的许可声明。
