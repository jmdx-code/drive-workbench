# 1.2.2 验收记录

日期：2026-10-21。

## 行为

新建递归所有权转让统一采用“尽量完成”，移除跳过模式开关。能转让的继续处理，明确不可转让的子项单独记录为已跳过。移动至目标根目录和移除原账号访问仍是独立设置，不自动扩大操作范围。历史任务保留已冻结的执行策略。

完整扫描后，在执行预览中突出提示“当前文件夹中有 X 个项目的所有者不是你”，并展示跳过项的原所有者。计数覆盖本次扫描的后代，不受所有者筛选隐藏；父子重复选择不重复计数。无法确认所有者的项目另行提示，不误报为他人所有。预览和提示不执行网盘写入，用户仍通过“确认执行”提交。

父文件夹必须成功转让。限流、授权异常、网络超时、结果未知、接收后的复核失败、目录移动失败和权限清理失败仍按失败或待对账处理。跳过项目保留原所有者，移动目录可能改变继承访问，不保证目标账号能访问跳过项。未勾选包含后代时，仅处理所选对象，不检查或转让其后代。
