# 云盘工作台图标

以现有祖母绿配色为基础，用白色云朵与文件夹结合，表达云端文件管理。采用透明外边缘，供 Windows 程序、任务栏、窗口及应用侧栏统一使用。

- `app-icon-source.png`：生成的原始图标，保留以供后续调整。
- `app-icon.ico`：16、24、32、48、64、128、256 像素，供 Windows EXE 使用。
- `../../public/app-icon.png`：512 像素运行用图标。
- 生成方式：内置 imagegen，透明背景。PNG 缩放和 ICO 封装由 `scripts/branding.mjs` 完成。
- 重新构建：`npm run build`；EXE 资源在本地构建和正式打包时自动写入。

## 原始提示词

Create a polished production app icon for a Windows SaaS desktop product called Drive Workbench (cloud file and permissions management). One centered icon only, square 1024x1024 canvas with transparent exterior. A deep emerald green rounded square tile, generous rounded corners, nearly fills canvas with 7% transparent margin. Inside: a bold elegant white cloud outline seamlessly joined to a small orderly folder shape at the lower right, suggesting organized cloud files. Very simple distinctive geometry, balanced optical centering, medium thick strokes, clear silhouette readable at 16px. Refined subtle tonal emerald gradient and restrained soft dimensional detail, professional premium software branding. Flat front view, crisp clean edges. No letters, text, arrows, Google branding, mockup, surrounding objects, watermark, decorative background, or exaggerated shadows. The icon must remain strong and legible at tiny taskbar size.
